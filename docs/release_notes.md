# Release notes

## Staged public snapshot

The current snapshot publishes the repository layout, environment metadata,
configuration shape, command-line entry points, and non-core API boundaries.
The SAGE-specific optimization implementation, datasets, checkpoints,
run-record files, and reported result tables are withheld from this snapshot.

## Planned final release

The final release will add the cleaned implementation, complete configuration
files, reproducibility instructions, third-party notices, and a provenance-safe
run manifest after internal review and de-identification.
