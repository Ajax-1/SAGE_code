# SAGE

**Shadow-Adaptive Geometric Supervision for Earth Observation Gaussian Splatting**

**Public release status: Coming soon.**

The SAGE implementation and configuration package are not yet publicly released. A cleaned code, configuration, and run-record package will be prepared for public release after acceptance following internal review and de-identification of project-specific assets and paths; the fixed parameters and random seeds used in this study are reported in the manuscript.

This repository is currently a public landing page and is intentionally **not a runnable release**. It contains no training implementation, dataset, checkpoint, experiment result, run record, or project-specific filesystem path. The small interface sketch in [`src/sage_interface.py`](src/sage_interface.py) is provided only to show the planned public API; it does not implement the method.

After acceptance and internal review, the release will be expanded with the cleaned implementation, configuration templates, installation and reproducibility instructions, and a provenance-safe run manifest. Release contents will be reviewed and de-identified before publication.

For the current scientific description and reported settings, please refer to the manuscript:

> SAGE: Shadow-Adaptive Geometric Supervision for Earth Observation Gaussian Splatting
